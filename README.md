## 🎓 About This Project

KEMOS Donation was designed and built as a **school project in 2025** while studying IT at Strathmore University. It is a complete working prototype that runs locally, and it comes with full project documentation (requirements, design and system overview) in the [`/docs`](./docs) folder.

It is not currently deployed publicly. The goal of the project was to practise planning, designing and building a real-world style web application from start to finish.

---

## ✨ Why KEMOS Donation?

Giving should feel simple and trustworthy. Too many donation pages are slow, confusing or unclear about where the money goes. KEMOS Donation is built around three ideas:

- **Simple.** A visitor should be able to donate in under a minute, on any phone.
- **Transparent.** Donors can see what a cause needs and how much has been raised.
- **Trustworthy.** Clear information, clean design and no distractions between a donor and their gift.

## 🚀 Features

- 🎯 **Clear donation flow** - choose an amount, add your details, give

## 🏁 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) 18 or newer
- npm, yarn or pnpm

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/your-username/kemos-donation.git

# 2. Go into the project folder
cd kemos-donation

# 3. Install dependencies
npm install

# 4. Set up environment variables
cp .env.example .env.local

# 5. Start the development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser and you're in.

### Environment Variables

Create a `.env.local` file in the project root:

```env
NEXT_PUBLIC_SITE_URL=http://localhost:3000
# Add your payment and API keys here. Never commit real keys to GitHub.
```
